# Verifica dei fatti

Controlla le affermazioni che reggono le conclusioni. Segui le prove, senza conclusioni
decise in anticipo.

## Per ogni affermazione

1. **Identifica** l'affermazione in una frase verificabile.
2. **Risali alla fonte primaria**: studio, dataset, documento ufficiale.
3. **Valuta la fonte**: autorità e competenza, qualità della pubblicazione (peer review,
   standard editoriali), metodologia (disegno, campione, significatività), data,
   indipendenza (finanziatori, conflitti di interesse).
4. **Confronta** con almeno due fonti indipendenti.
5. **Controlla il contesto**: periodo, luogo, citazioni fuori contesto.
6. **Cerca bias**: interessi, tono di parte, fonti anonime o solo di opinione.

## Verdetti

| Verdetto | Significato |
| --- | --- |
| TRUE | Accurata e ben sostenuta dalle prove |
| MOSTLY_TRUE | Quasi accurata, con piccole imprecisioni |
| PARTLY_TRUE | Contiene elementi veri, ma è incompleta o fuorviante |
| MOSTLY_FALSE | Largamente inaccurata, con poca verità |
| FALSE | Falsa o senza prove |
| UNVERIFIABLE | Le prove disponibili non bastano |

Aggiungi la confidenza (high, medium, low). Se le prove sono insufficienti, dillo e
suggerisci quale verifica manca. Dedica più sforzo alle affermazioni più importanti.

## Output

Aggiungi in `report.md` (o in `fact-check.md`) una tabella: affermazione, verdetto,
confidenza, fonti, note.
