description: Riferimento rapido per livelli, skill e comandi di ponytail
---

Mostra il riferimento rapido di ponytail. One-shot, non cambiare nulla: non cambiare modalità, non scrivere file flag, non persistere nulla. Livelli: /trinity:ponytail:ponytail lite (costruisci ciò che è chiesto, nomina in una riga l'alternativa più pigra), /trinity:ponytail:ponytail (full, la scala di default: YAGNI poi stdlib poi native poi one line poi minimum). Comandi: /trinity:ponytail:ponytail-review (revisione over-engineering delle modifiche correnti), /trinity:ponytail:ponytail-audit (audit over-engineering dell'intero repo), /trinity:ponytail:ponytail-debt (raccogli i commenti ponytail: in un ledger tracciato), /trinity:ponytail:ponytail-gain (scoreboard dell'impatto misurato dal benchmark), /trinity:ponytail:ponytail-help (questa card). Disattiva con 'stop ponytail', 'normal mode', o /trinity:ponytail:ponytail off; riprendi quando vuoi con /trinity:ponytail:ponytail. La modalità di default è full; cambiala con la variabile d'ambiente PONYTAIL_DEFAULT_MODE (off|lite|full) o con un file di config in ~/.config/ponytail/config.json con {"defaultMode": "lite"}. Ordine di risoluzione: env var, poi file di config, poi full.
